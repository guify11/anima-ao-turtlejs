# animaçao-turtlejs
> este e um projeto feito no nivel 1 de programaçao no tumo para mais informaçoes consulte [este link](https://tumo.pt)

O projeto animaçao-turtlejs como o nome diz cria uma animaçao usando a bibliotea [turtlejs](https://https://github.com/bjpop/js-turtle)

## animaçao 
a animaçao que este projeto cria consiste em um stick man a entrar numa casa
